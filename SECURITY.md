# Security Policy

## Supported Versions

The following versions are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please open an issue on the [GitHub repository](https://github.com/jcbscott/Verification-LVL1-Tracker/issues) with the label `security`. You can expect an initial response within 48 hours.

Please include the following in your report:
- A description of the vulnerability
- Steps to reproduce it
- Potential impact

We will review the report and provide updates as the investigation progresses. If the vulnerability is accepted, a fix will be released in the next patch version. If declined, a rationale will be provided.
